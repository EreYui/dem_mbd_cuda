## 1. 审计结论与边界

原程序的时间步由 CPU 颗粒 AoS、CPU 空间网格、接触遍历、颗粒 leapfrog，以及可选的通用 MBD 求解构成。纯 DEM 和 DEM–MBD 共用颗粒/接触模型；耦合路径在每步将颗粒对三角网格的合力和相对瞬时质心力矩送入 `DynEqnBodySet`。

迁移前逐文件比较了只读 CPU 数值基准和只读 CUDA 参考。仅复用了参考项目中通用的 SoA、CUDA 生命周期、排序网格、接触 kernel、归约与积分思路，并进行了动态尺寸、物理模型和输出语义泛化。未引入任何特定机器人类、步态、固定刚体数量、固定广义坐标或固定 KKT 维数。通用 MBD 仍以本项目 `multibody.cpp`、`dyneq.cpp`、`multibody.h` 为准。

## 2. 最终架构

### 数据常驻与布局

- 主机读取原 AoS 输入，初始化时一次转换/上传到设备 SoA。
- 颗粒质量、惯量、半径、稳定 ID、状态、位置、速度、四元数、角速度、半步量、加速度、力和力矩持续驻留 GPU。
- 墙面、动态刚体状态、局部/世界三角形、颗粒网格、三角形网格和接触历史持续驻留 GPU。
- 粒子网格按 64 位单元键稳定排序；三角形网格采用两遍计数和精确容量增长，不再固定每三角形占用单元数。
- 刚体数、各刚体三角形数、总三角形数和颗粒数均为运行时尺寸。
- 每个刚体具有独立 `state`：0 为载荷驱动，1 为固定，2 为按 CSV 线速度/角速度规定运动；非动力刚体仍参与 GPU 接触和载荷归约。

### 每步数据流

```text
CPU 通用 MBD 状态（仅耦合时）
        │ 13 doubles/body H2D
        ▼
GPU 三角形变换 → 颗粒/三角形排序网格 → 邻域接触 kernel
        → 颗粒力/力矩汇总 → 刚体六分量载荷归约 → 颗粒 leapfrog
        │
        ├─ 6 doubles/body D2H → CPU DynEqnBodySet
        └─ 仅输出步：按启用字段下载到双缓冲后台写盘
```

纯 DEM 时间步没有刚体状态/载荷交换。DATA1 的两刚体耦合步常规交换约 304 B：208 B 刚体状态上行、96 B 载荷下行，另有少量诊断标量。输出步的下载量由开关决定；1704 颗粒全状态约 177,216 B，全颗粒力约 327,168 B。刚体×颗粒输出数组仅在对应输出开启时分配。

### kernel 职责

- 颗粒网格：计算带范围检查的 64 位单元键并稳定排序。
- 三角形网格：变换世界三角形、两遍计算覆盖单元、排序键/三角形索引。
- 接触：颗粒—颗粒、颗粒—墙面、颗粒—任意刚体三角面；包含法向弹簧/阻尼、切向历史、静/动摩擦、滚动、扭转和黏聚。
- 汇总：颗粒总力/力矩，刚体合力及相对该刚体瞬时质心的合力矩。
- 积分：保持原 leapfrog 的半步初始化、位置/四元数推进和速度/角速度完成顺序。

kernel 启动后使用可定位的 CUDA 错误检查；正式循环不做无条件 `cudaDeviceSynchronize`。接触历史不会绑定排序下标：颗粒接触以稳定 ID 对为键，刚体三角面接触以稳定颗粒 ID、刚体 ID、局部三角形 ID 为键。

## 3. 风险控制

- 默认 `double`，未使用 `--use_fast_math`。
- 分离 PP/PT/PW 参数路由。
- 三角形接触保持基准圆—三角形面积/边界判定的物理语义。
- 检查稳定颗粒 ID 重复、21 位网格坐标范围、32 位索引乘积、三角网格条目计数和接触历史容量。
- 接触历史溢出累计记录并在诊断点抛错；输出报告历史槽高水位。
- 异步输出帧具有 `Free/Filling/Queued/Writing` 状态，后台异常传回主线程，GPU 或写线程未完成时不会复用缓冲。

主要数据竞争由双精度原子累加和按颗粒 owner 的历史槽解决。不同线程归约顺序会造成末位浮点差异，因此验证使用绝对/相对误差而非逐位比较。

## 7. 输出兼容与已知限制

文件名、目录、字段数、字段顺序和步编号保持原接口。颗粒状态、颗粒力、刚体状态及刚体六分量合力/力矩与基准数值一致。

`force_bodys/FB.*` 的 19 分量“接触明细”存在一个有意记录的边界：旧串行遍历在同一刚体/颗粒同时命中多个三角面时保留最后遍历三角面的明细，结果依赖三角遍历次序；CUDA 为避免数据竞争，对同一刚体/颗粒的各接触分量求和，并对穿透深度取最大值。因此该诊断文件的字段和格式兼容，但多三角同时接触时明细值不保证逐值一致；真正用于 MBD 的六分量合力/力矩以及颗粒总力保持验证一致。恢复旧“最后三角面覆盖”会引入非确定性，未将其作为正式物理语义。

接触历史使用每颗粒有限槽位；异常高配位时程序会报告容量超限并停止，不会静默丢历史。现有几何基准和 DATA1 已通过，但新模型、极端网格尺度或超大算例仍应先运行短步 CTest/Compute Sanitizer，再开展长时间计算。
